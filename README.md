# 个人投资仓位管理与复盘系统

本项目是本地运行的 MVP 第一版，用于个人股票投资的仓位管理、风控纪律提醒、指数记录和每日复盘，不包含自动交易。

## 启动

```bash
npm install
npm run py:install
npm run dev
```

默认地址：

- 前端：http://127.0.0.1:5173
- API：http://127.0.0.1:3100
- SQLite 数据库：`data/fupan.sqlite`
- Python 行情依赖：`requirements.txt`，默认使用 `C:\Users\Huzhiwei\AppData\Local\Programs\Python\Python314\python.exe`

## 已实现

- 投资控制台：总资产、现金、持仓市值、总仓位、今年收益率、历史最高权益、当前回撤、风险状态、风控提醒。
- 持仓管理：新增、编辑、删除、手动更新价格，自动计算市值、浮盈亏和仓位比例。
- 风控规则：账户级、个股级、行业级规则，行情/价格更新后自动生成提醒。
- 指数记录：支持上证指数、深证成指、创业板指、科创50、沪深300、中证500的手动记录和市场状态判断。
- 自动行情更新：点击“更新行情”后，通过 Python + akshare 获取持仓股和主要指数日频行情，写回 SQLite，并更新当天复盘快照。
- 通达信本地行情：默认优先读取 `D:\HTZQ\vipdoc\sh\lday` 和 `D:\HTZQ\vipdoc\sz\lday` 下的 `.day` 文件；读取失败后可按设置回退 akshare。
- 系统设置：支持配置通达信安装目录、是否优先本地行情、是否启用 akshare 备用，并可检测本地数据目录。
- 每日复盘：按日期生成快照，自动包含账户、持仓、提醒、指数和市场状态，并支持手动填写判断、计划、情绪和纪律执行。
- 导出：持仓和复盘支持 CSV 导出。
